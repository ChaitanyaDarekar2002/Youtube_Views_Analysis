# 🇮🇳 India YouTube Views Analysis

## 📊 Project Overview

This project analyzes **YouTube channel performance in India** using **Power BI**. The dashboard provides insights into views, subscribers, videos, channels, and topics of influence.

## 🎯 Objectives

- Analyze YouTube views and channel performance
- Identify channels with the highest subscribers
- Compare total views across channels
- Analyze videos by topic/category
- Identify influential YouTube topics
- Compare channel performance using interactive filters

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard & Data Visualization
- **Excel / CSV** – Dataset
- **Data Analysis** – YouTube channel and performance analysis

## 📈 Dashboard Features

- 📺 Total Views by Channel
- 👥 Total Subscribers by Channel
- 🎥 Total Videos by Channel
- 🔥 Views by Topic of Influence
- 📊 Top YouTube Channels
- 🎯 Topic-wise Analysis
- 🔎 Interactive Topic Filters

## 📊 Key Insights

- **T-Series** has the highest subscriber count among the analyzed channels.
- **Music** is one of the major influential topics based on total videos.
- The dashboard compares channels based on **views, subscribers, and videos**.
- Different categories such as **Music, Celebrity, Education, Fashion, Marketing, News, and Gaming** can be analyzed interactively.
